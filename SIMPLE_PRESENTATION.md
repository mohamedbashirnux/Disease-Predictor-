## Slide 4: How It Works
**Simple 4-Step Process:**

**1.** Select symptoms from 123 options 📝
**2.** Choose ML model (Random Forest/Naive Bayes) 🤖
**3.** Set number of predictions (Top 1, 3, or 5) 🎯
**4.** Get instant results with confidence scores ✅
